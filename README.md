CMPM 146 Programming #5

This project uses a genetic algorithm to generate Super Mario Bros. levels.

Two level representations are included:

Individual_Grid: stores the full 16 x 200 tile map.

Individual_DE: stores design elements such as holes, platforms, enemies, coins, stairs, and pipes.

Current Test

Both Grid and DE were tested locally with a population of 40.

The saved Grid and DE candidates are 16 x 200 levels and were reported as solvable by the provided metrics.
